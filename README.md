# Оптимизация маршрутов доставки в условиях стохастического трафика и вероятностных ограничений

Проект посвящён исследованию и программной реализации методов решения задачи маршрутизации транспортных средств с временными ограничениями в условиях случайного времени движения и влияния случайных факторов.


## Бизнес-контекст и прикладные задачи

Цель проекта — минимизация совокупных логистических расходов (фиксированная стоимость выхода транспорта на линию + переменный тариф за время движения) при гарантированном соблюдении заданного уровня надёжности (порога совместной вероятности своевременной доставки alpha).

### Решаемые прикладные задачи:

1) Исключение штрафных санкций за срыв сроков путём контроля совместной вероятности своевременного прибытия ко всем клиентам.
2) Оптимизация загрузки автопарка через построение маршрутных цепочек (до 3 точек) с учётом грузоподъёмности и совокупного риска опоздания.
3) Достижение баланса между числом задействованных машин и суммарным пробегом.
4) Обеспечение масштабируемости вычислений для работы в диспетчерских системах реального времени (время расчёта плана не более нескольких секунд).

## Архитектура двухэтапного алгоритма

Вместо вычислительно сложных методов стохастического программирования «онлайн» в проекте реализован принцип двухстадийной декомпозиции:

1) Этап стохастической предобработки (Алгоритм свёртки распределений):
   Описание сети: склады отправления с запасами груза, точки доставки с объёмами спроса и директивными сроками.
   Задание времени движения в виде дискретных распределений вероятностей, как для выездов со складов, так и для межточечных переездов.
   Комбинаторное порождение потенциальных маршрутов с фильтрацией по грузоподъёмности кузова.
   Пошаговая дискретная свёртка случайных величин времени вдоль каждого маршрута с контролем директивных сроков.
   Отсечение заведомо нереализуемых стратегий (с вероятностью успеха P = 0).
   Логарифмирование вероятностей ln(P) для последующей линеаризации модели.
   Результа: сокращение пространства поиска и формирование компактного набора допустимых кандидатов.

2) Стадия детерминированной дискретной оптимизации (MIP / ILP):
   Формирование целевой функции путем минимизации суммарных затрат на базе бинарных переменных назначения.
   Линеаризованное совместное ограничение риска сумма логарифмов вероятностей выбранных маршрутов должна быть не меньше логарифма заданного порога alpha.
   Решение задачи методами целочисленного линейного программирования.


## Исследуемые методы

В рамках проекта исследуются четыре алгоритма:

1) Метод полного перебора:

   Используется для верификации математической модели и поиска абсолютного эталона на малых размерностях. Служит для наглядной демонстрации границы применимости точного перебора при росте размерности задачи.

2) Открытые алгоритмы целочисленного программирования (CBC / PuLP):

   Основной вычислительный инструмент. Реализует метод ветвей и отсечений (Branch-and-Cut), находит строго глобальный оптимум без искусственных ограничений на число переменных задачи.

3) Коммерческий решатель дискретной оптимизации (IBM CPLEX):

   Используются в качестве контрольного бенчмарка для проверки скорости сходимости и валидации математической строгости полученных решений.

4) Приближённая жадная эвристика с механизмом адаптивного отката:

   Помогает оценить работу точных методов на фоне приблеженных.
